	1. Command Mode
	2. Insert Mode
	3. Execution mode
	4. Visual Mode
----------------------
	1. Command Mode:
		i 	=> insert mode
		esc	=> mode chya baher yeto.
		:wq	=> write & quite 	
		gg	=> top la jate
		G	=> bottom la jate		

		yy 	=> 1 line copy
		10yy	=> 10 line copy

		p	=> paste - cursor chya khali
		P	=> paste - cursor chya var
		dd	=> delete single line
		20dd	=> delete 20 lines
		dw	=> delete word
		u	=> undo (return changes)

2. Insert Mode
		i	=> insert mode madhe janya sathi
		I	=> Line chya start la janya sathi
		A	=> Line chya last la janya sathi
		O	=> create new line above the cursor
		o 	=> create new line below the cursor

3. Execution Mode

		:wq	=> write & quite
		:w	=> only write
		:q 	=> only quite
		:w! 	=> forcefully write
		:q!	=> forcefully quite
		:set nu	=> set number
		:set nonu	=> remove number	
		:/word		=> search
		:nohl		=> no highlight
4. Visual Mode - reading mode
		v	=> visual mode
		esc	=> exit from visual mode
		arrow	=> scroll
